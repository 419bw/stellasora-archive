# 《星塔旅人》官方主线剧情全篇总览

游戏主线记录了主角与空白旅团在星塔历 996 年踏上诺瓦大陆探索星塔的壮丽史诗。每一章节均包含**章节拓扑分支路线图 (Mermaid DAG)**，并按关卡节点独立拆分为详细剧情文档（包含关卡信息、**官方跳过剧情概要 SetIntro** 与 **逐句全角色台词剧本 SetTalk/SetChoice**）。
