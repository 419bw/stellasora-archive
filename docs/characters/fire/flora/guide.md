# 紫槿 官方流派与配队战斗指南

## 1. 核心定位与机制
- **定位**：火系核心旅人 (4 星)
- **战斗风格**：擅长利用火系印记与多样化战术机制进行持续压制与爆发输出。

## 2. 官方推荐战斗流派
- **官方推荐流派 1**：提升魔术帽数量并使其可回收的持续群伤型流派。
- **官方推荐流派 2**：产生分身，使普攻分裂并持续附加印记的穿透型流派。
- **官方推荐流派 3**：炎蝶数量提升，炎蝶可持续分裂的印记附加流派。
- **官方推荐流派 4**：沐蝶数量提升，提升主控伤害的暴击流派。

## 3. 配队协同与印记联动
- **印记附着与引爆**：优先搭配具有快速挂载火系印记或具备高削韧能力的均衡/辅助旅人。
- **主控与援护战术分工**：
  - **主控登场**：利用「登台暖场」控场与「三幕式」打出高频伤害，结合绝招「天火涅槃」在敌方虚弱时爆发。
  - **援护后台**：前台队友破韧后瞬间触发「伴舞焰蝶」，登场瞬发压制。

## 4. 关键养成质变节点
- **突破 3 阶觉醒**：不仅解锁觉醒立绘，而且大幅度提升成长属性，是质变关键期。
- **潜能优先级**：潜能 1 与 潜能 2 是核心机制质变点，显著优化循环手感并带来机制层数加成。
