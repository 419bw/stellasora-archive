# 紫槿 技能机制与潜能详解

## 1. 战斗技能全解析

### 普通攻击：三幕式
- **简述**：连续生成火鸟，造成伤害。
- **详细机制**：
  > 连续生成火鸟，造成伤害。

一段：攻击力[数值]火系普攻伤害

二段：攻击力[数值]火系普攻伤害

三段：攻击力[数值]火系普攻伤害

### 闪避动作：闪避动作
- **机制**：快速位移规避伤害，拥有极限闪避无敌帧，成功闪避可衔接疾跑或反击连携。

### 主控技能：登台暖场
- **简述**：扔出魔术帽，连续造成伤害，并附加「火系印记：圣焰」。
- **详细机制**：
  > 扔出「魔术帽」，每0.5秒造成攻击力[数值]的火系技能伤害，并附加「火系印记：圣焰」，持续5秒。

施放技能时，提升全队[数值][数值]，持续[数值]秒。

### 援护技能：伴舞焰蝶
- **简述**：生成3只「沐蝶」和3只「炎蝶」，分别作用于主控角色和目标。

「沐蝶」：提升主控角色[数值]和[数值]。

「炎蝶」：造成火系伤害，并附加「火系印记：圣焰」。
- **详细机制**：
  > 生成3只「沐蝶」和3只「炎蝶」，分别作用于主控角色和目标。

「沐蝶」：提升主控角色[数值][数值]，并且每只沐蝶额外提升主控角色[数值][数值]，持续[数值]秒。

「炎蝶」：造成攻击力[数值]的火系技能伤害，并附加1层「蝶之印」和「火系印记：圣焰」。

### 绝招：天火涅槃
- **简述**：生成天火凤凰，造成范围伤害后，幻化成「凤凰卵」，并附加「火系印记：圣焰」。
- **详细机制**：
  > 生成天火凤凰，造成攻击力[数值]的范围火系绝招伤害后，幻化成「凤凰卵」，存在8秒。

「凤凰卵」牵引目标，每秒造成攻击力[数值]的火系绝招伤害，并附加「火系印记：圣焰」。

## 3. 专属潜能节点 (Potentials 1~5)
### 潜能 1：技能额外扔出2顶「魔术帽」。
- **效果**：主控技「登台暖场」额外扔出2顶「魔术帽」，每0.25秒造成攻击力[数值]的火系技能伤害。

### 潜能 2：提升紫槿技能伤害。

解锁二段技能，「魔术帽」移动到最大距离或施放二段时，会迅速折返。
- **效果**：紫槿技能伤害提升[数值]。

解锁二段技能，「魔术帽」移动到最大距离或施放二段时，会迅速折返。

### 潜能 3：施放技能后提升普攻火鸟数量。
- **效果**：施放主控技「登台暖场」后，普攻可同时生成3只火鸟，持续[数值]秒。

### 潜能 4：施放技能时生成分身。
- **效果**：施放主控技「登台暖场」时，生成1个分身。

分身拥有紫槿33%攻击力，造成普攻伤害，持续8秒。

### 潜能 5：「魔术帽」伤害提升，可牵引目标。
- **效果**：「魔术帽」造成的[数值]提升[数值]，可持续牵引弱小的目标。
