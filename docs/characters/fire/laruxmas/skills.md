# 菈露（圣夜） 技能机制与潜能详解

## 1. 战斗技能全解析

### 普通攻击：雪愿勇士
- **简述**：挥舞皮鞭，进行多段攻击。

随身携带玩具「「胡桃上校」」攻击目标。

当「「胡桃上校」」的「士气」叠满可进化为玩具「「卷毛大将」」。
- **详细机制**：
  > 挥舞皮鞭，造成多段攻击。

一段：攻击力[数值]火系普攻伤害

二段：攻击力[数值]火系普攻伤害

三段：攻击力[数值]火系普攻伤害

四段：攻击力[数值]x5火系普攻伤害

五段：攻击力[数值]x3火系普攻伤害

随身携带1个玩具「「胡桃上校」」攻击目标，其普攻造成攻击力[数值]火系仆从伤害并获得1层「士气」。

当「「胡桃上校」」的「士气」叠加至[数值]层，会进化为玩具「「卷毛大将」」，其普攻造成攻击力[数值]x2火系仆从伤害并消耗4层「士气」。

当「「卷毛大将」」的「士气」全部耗尽，会退化为「「胡桃上校」」。

### 闪避动作：闪避
- **机制**：快速位移规避伤害，拥有极限闪避无敌帧，成功闪避可衔接疾跑或反击连携。

### 主控技能：应鞭而动
- **简述**：挥舞皮鞭，抽打前方目标，为玩具增加「士气」并触发玩具的协同技能。

主控技可触发「火系印记」，产生「灼炎」。
- **详细机制**：
  > 挥舞皮鞭，抽打前方目标，造成攻击力[数值]的范围火系技能伤害，命中目标时为玩具增加1层「士气」。当玩具处于主控技伤害范围内时，额外增加1层「士气」。

施放主控技时，玩具会施放协同技能，攻击目标。

「「胡桃上校」」猛击地面，造成攻击力[数值]的范围火系仆从伤害并获得1层「士气」。

「「卷毛大将」」挥舞双刀，造成攻击力[数值]x2的范围火系仆从伤害。

主控技「[数值]」可触发「火系印记」，产生「灼炎」：造成攻击力[数值]的火系印记伤害。

### 援护技能：先礼后兵
- **简述**：指挥炮台向目标发射「礼盒炮弹」，造成伤害并附加「火系印记：圣焰」。

「礼盒炮弹」爆炸后会召唤玩具「「胡桃上校」」，持续攻击目标。
- **详细机制**：
  > 圣夜菈露指挥炮台，向目标发射4次「礼盒炮弹」，每次命中时造成攻击力[数值]的火系技能伤害，随后爆炸造成攻击力[数值]的范围火系技能伤害。

「礼盒炮弹」爆炸后在目标附近召唤1个玩具「「胡桃上校」」。

「「胡桃上校」」攻击目标造成攻击力[数值]的火系仆从伤害。

「礼盒炮弹」造成伤害时附加「火系印记：圣焰」。

### 绝招：甜梦欢舞
- **简述**：变身为玩具「菈露爵士」。

变身后使用枪械远程射击，「糖果齐射」取代主控技和援护技。
- **详细机制**：
  > 变身为玩具「菈露爵士」，获得基础最大生命[数值]的护盾，持续[数值]秒。

「菈露爵士」无法闪避和疾跑，使用枪械射击，贯穿目标造成攻击力[数值]的火系绝招伤害。圣夜菈露的主控技和援护技变为「糖果齐射」。

「糖果齐射」对前方目标造成攻击力[数值]x5的范围火系绝招伤害，冷却4秒。
