# 埃莉诺 官方流派与配队战斗指南

## 1. 核心定位与机制
- **定位**：风系核心旅人 (5 星)
- **战斗风格**：擅长利用风系印记与多样化战术机制进行持续压制与爆发输出。

## 2. 官方推荐战斗流派
- **官方推荐流派 1**：通过持续恢复战术储能，高频释放强化后的十字重斩的普攻流派。
- **官方推荐流派 2**：娴熟地操控哨兵，使其面对海量敌人造成大范围伤害的技能流派。
- **官方推荐流派 3**：随着跳跃下砸而持续扩增伤害范围和攻击次数，面对海量敌人涌来，也可以轻松自如地应对。
- **官方推荐流派 4**：持续产生长时间存在的哨兵，使其快速攻击定点目标，对小范围内的敌人造成集中性伤害。

## 3. 配队协同与印记联动
- **印记附着与引爆**：优先搭配具有快速挂载风系印记或具备高削韧能力的均衡/辅助旅人。
- **主控与援护战术分工**：
  - **主控登场**：利用「哨卫展开」控场与「战术连式」打出高频伤害，结合绝招「火力覆盖」在敌方虚弱时爆发。
  - **援护后台**：前台队友破韧后瞬间触发「武装强袭」，登场瞬发压制。

## 4. 关键养成质变节点
- **突破 3 阶觉醒**：不仅解锁觉醒立绘，而且大幅度提升成长属性，是质变关键期。
- **潜能优先级**：潜能 1 与 潜能 2 是核心机制质变点，显著优化循环手感并带来机制层数加成。
