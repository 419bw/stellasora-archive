# 杏子 官方流派与配队战斗指南

## 1. 核心定位与机制
- **定位**：风系核心旅人 (4 星)
- **战斗风格**：擅长利用风系印记与多样化战术机制进行持续压制与爆发输出。

## 2. 官方推荐战斗流派
- **官方推荐流派 1**：更高概率产生「风爆」，击飞并使敌人受到更多伤害的流派。
- **官方推荐流派 2**：喷射激光贯通伤害，且援护角色通过触发印记也可发动激光的流派。
- **官方推荐流派 3**：提升风墙数量并附加护盾，提升队伍生存能力的流派。
- **官方推荐流派 4**：风墙持续造成伤害并增强穿越的友方飞弹，适合与远程主控搭配的流派。

## 3. 配队协同与印记联动
- **印记附着与引爆**：优先搭配具有快速挂载风系印记或具备高削韧能力的均衡/辅助旅人。
- **主控与援护战术分工**：
  - **主控登场**：利用「嘭嘭飞弹」控场与「伶牙俐齿」打出高频伤害，结合绝招「原野之唤」在敌方虚弱时爆发。
  - **援护后台**：前台队友破韧后瞬间触发「驻足逆风」，登场瞬发压制。

## 4. 关键养成质变节点
- **突破 3 阶觉醒**：不仅解锁觉醒立绘，而且大幅度提升成长属性，是质变关键期。
- **潜能优先级**：潜能 1 与 潜能 2 是核心机制质变点，显著优化循环手感并带来机制层数加成。
