# 夏花 官方流派与配队战斗指南

## 1. 核心定位与机制
- **定位**：风系核心旅人 (5 星)
- **战斗风格**：擅长利用风系印记与多样化战术机制进行持续压制与爆发输出。

## 2. 官方推荐战斗流派
- **官方推荐流派 1**：大幅提升吹风时长和范围的持续伤害流派。
- **官方推荐流派 2**：吹风追加聚怪效果并可贯穿攻击的爆发伤害流派。
- **官方推荐流派 3**：连续生成持续追踪目标的花瓣的单体流派。
- **官方推荐流派 4**：生成花海，并可协同风系伤害的群伤流派。

## 3. 配队协同与印记联动
- **印记附着与引爆**：优先搭配具有快速挂载风系印记或具备高削韧能力的均衡/辅助旅人。
- **主控与援护战术分工**：
  - **主控登场**：利用「疾风绽放」控场与「爆裂风弹」打出高频伤害，结合绝招「芳香龙卷」在敌方虚弱时爆发。
  - **援护后台**：前台队友破韧后瞬间触发「落英缤纷」，登场瞬发压制。

## 4. 关键养成质变节点
- **突破 3 阶觉醒**：不仅解锁觉醒立绘，而且大幅度提升成长属性，是质变关键期。
- **潜能优先级**：潜能 1 与 潜能 2 是核心机制质变点，显著优化循环手感并带来机制层数加成。
