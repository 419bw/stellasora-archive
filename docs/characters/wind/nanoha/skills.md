# 花原 技能机制与潜能详解

## 1. 战斗技能全解析

### 普通攻击：花漫落
- **简述**：发射多枚飞镖。
- **详细机制**：
  > 发射多枚飞镖。

一段：攻击力[数值]x2风系普攻伤害

二段：攻击力[数值]x2风系普攻伤害

三段：攻击力[数值]x3风系普攻伤害

### 闪避动作：闪避动作
- **机制**：快速位移规避伤害，拥有极限闪避无敌帧，成功闪避可衔接疾跑或反击连携。

### 主控技能：花风舞
- **简述**：发射往返飞行的向日葵飞镖。主控技可触发「风系印记」，产生「绽放」。
- **详细机制**：
  > 发射2枚向日葵飞镖，往返飞行共4轮，每次可造成攻击力[数值]的风系技能伤害。

主控技「花风舞」可触发「风系印记」，产生「绽放」：造成攻击力[数值]的范围风系印记伤害。

### 援护技能：花未凋
- **简述**：生成爆散向日葵，发射多个飞镖。援护技可触发「风系印记」，产生「绽放」。
- **详细机制**：
  > 生成爆散向日葵，发射12枚飞镖，每枚造成攻击力[数值]风系技能伤害。

援护技「花未凋」可触发「风系印记」，产生「绽放」：造成攻击力[数值]的范围风系印记伤害。

### 绝招：花镜月
- **简述**：产生分身协助战斗。分身可触发「风系印记」，产生「绽放」
- **详细机制**：
  > 产生2名不移动的分身协助战斗，分身发射飞镖造成花原攻击力[数值]x2、[数值]x2、[数值]x3的风系绝招伤害。

分身存在时间10秒，最多存在2名。

分身的伤害可触发「风系印记」，产生「绽放」：造成攻击力[数值]的范围风系印记伤害。

## 3. 专属潜能节点 (Potentials 1~5)
### 潜能 1：花原造成多次普攻伤害后，额外造成范围风系普攻伤害。
- **效果**：花原对目标造成3次普攻伤害后，额外造成攻击力[数值]的范围风系普攻伤害。

### 潜能 2：施放主控技后，普攻时额外发射飞镖。
- **效果**：施放主控技「花风舞」后10秒内，普攻时额外发射3枚可穿透的飞镖，每枚造成攻击力[数值]的风系普攻伤害。
