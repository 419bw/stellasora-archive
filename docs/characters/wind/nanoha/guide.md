# 花原 官方流派与配队战斗指南

## 1. 核心定位与机制
- **定位**：风系核心旅人 (5 星)
- **战斗风格**：擅长利用风系印记与多样化战术机制进行持续压制与爆发输出。

## 2. 官方推荐战斗流派
- **官方推荐流派 1**：提升攻速与飞镖数量，多次命中还可造成额外群伤的流派。
- **官方推荐流派 2**：提升飞镖伤害范围并可多段伤害，适合对付大型目标的流派。
- **官方推荐流派 3**：命中多目标触发风印记，即可大幅缩短冷却并再次发动的群伤型流派。
- **官方推荐流派 4**：持续跟踪追击目标，并逐渐提升引爆伤害的单体型流派。

## 3. 配队协同与印记联动
- **印记附着与引爆**：优先搭配具有快速挂载风系印记或具备高削韧能力的均衡/辅助旅人。
- **主控与援护战术分工**：
  - **主控登场**：利用「花风舞」控场与「花漫落」打出高频伤害，结合绝招「花镜月」在敌方虚弱时爆发。
  - **援护后台**：前台队友破韧后瞬间触发「花未凋」，登场瞬发压制。

## 4. 关键养成质变节点
- **突破 3 阶觉醒**：不仅解锁觉醒立绘，而且大幅度提升成长属性，是质变关键期。
- **潜能优先级**：潜能 1 与 潜能 2 是核心机制质变点，显著优化循环手感并带来机制层数加成。
