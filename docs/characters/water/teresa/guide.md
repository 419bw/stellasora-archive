# 特丽莎 官方流派与配队战斗指南

## 1. 核心定位与机制
- **定位**：水系核心旅人 (4 星)
- **战斗风格**：擅长利用水系印记与多样化战术机制进行持续压制与爆发输出。

## 2. 官方推荐战斗流派
- **官方推荐流派 1**：技能段数提升并额外生成水波纹，提升伤害与印记能力的流派。
- **官方推荐流派 2**：施放技能后获得护盾，并随机提升队友能量的生存型流派。
- **官方推荐流派 3**：获得护盾，护盾中的主控角色的攻击会生成水波纹，适合近战主控的流派。
- **官方推荐流派 4**：生成可击退目标的浪域，提升浪域中的主控角色伤害，适合远程主控的流派。

## 3. 配队协同与印记联动
- **印记附着与引爆**：优先搭配具有快速挂载水系印记或具备高削韧能力的均衡/辅助旅人。
- **主控与援护战术分工**：
  - **主控登场**：利用「飞花潺流」控场与「横斩式」打出高频伤害，结合绝招「零距凝解斩」在敌方虚弱时爆发。
  - **援护后台**：前台队友破韧后瞬间触发「浪潮绝涌」，登场瞬发压制。

## 4. 关键养成质变节点
- **突破 3 阶觉醒**：不仅解锁觉醒立绘，而且大幅度提升成长属性，是质变关键期。
- **潜能优先级**：潜能 1 与 潜能 2 是核心机制质变点，显著优化循环手感并带来机制层数加成。
