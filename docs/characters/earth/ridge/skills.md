# 岭川 技能机制与潜能详解

## 1. 战斗技能全解析

### 普通攻击：萌芽炮弹
- **简述**：连续发射能量炮弹，造成伤害。
- **详细机制**：
  > 发射能量炮弹，每颗炮弹造成攻击力[数值]的地系普攻伤害，弹匣容量为24。

靠近目标时，挥舞铲子炮，造成攻击力[数值]的范围地系普攻伤害。

### 闪避动作：闪避动作
- **机制**：快速位移规避伤害，拥有极限闪避无敌帧，成功闪避可衔接疾跑或反击连携。

### 主控技能：麦豆回旋
- **简述**：挥舞铲子炮抛出种子，造成伤害。

施放技能后，填满弹匣，普攻获得强化。

主控技可触发「地系印记：地脉」。
- **详细机制**：
  > 挥舞铲子炮，造成攻击力[数值]的地系技能伤害。同时抛出种子，造成攻击力[数值]的范围地系技能伤害，并降低目标移速[数值]，持续[数值]秒。

施放技能后，填满弹匣，普攻获得强化：提升射速，且不消耗弹匣，持续[数值]秒。

主控技「麦豆回旋」可触发「地系印记：地脉」，造成攻击力[数值]的范围地系印记伤害。

### 援护技能：百花齐放
- **简述**：持续落下种子雨，连续造成伤害，并附加「地系印记：地脉」和「种球」。

「种球」：己方对附带种球的目标触发「地系印记」时，造成伤害。
- **详细机制**：
  > 持续落下种子雨，造成攻击力[数值]x6的范围地系技能伤害，并附加「地系印记：地脉」和「种球」。

「种球」：持续[数值]秒，己方对附带种球的目标触发「地系印记」时，造成岭川攻击力[数值]范围地系技能伤害。

### 绝招：丰收狂想曲
- **简述**：连续打击树树鼠战士，造成伤害。
- **详细机制**：
  > 连续打击树树鼠战士，造成攻击力[数值]x5、[数值]的范围地系绝招伤害。

## 3. 专属潜能节点 (Potentials 1~5)
### 潜能 1：主控技额外抛出种子。
- **效果**：主控技「麦豆回旋」额外抛出1颗种子。

### 潜能 2：主控技抛出的种子可变为麦豆射手：连续发射种子，造成伤害。
- **效果**：主控技「麦豆回旋」抛出的种子变为麦豆射手：连续发射种子，造成攻击力[数值]的地系技能伤害，持续8秒。

### 潜能 3：每发射一定数量的能量炮弹，下次普攻发射1颗巨型能量炮弹。
- **效果**：普攻「萌芽炮弹」每发射12颗能量炮弹，下次普攻发射1颗巨型能量炮弹：伤害范围提升100%，造成攻击力[数值]的地系普攻伤害。

### 潜能 4：提升岭川[数值]。普攻额外发射能量炮弹。
- **效果**：岭川[数值]提升[数值]，每次普攻额外发射2颗能量炮弹。

### 潜能 5：提升岭川[数值]和种子伤害范围。
- **效果**：岭川[数值]提升[数值]，种子伤害范围提升35%。
