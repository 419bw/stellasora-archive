# 斯帕克拉 技能机制与潜能详解

## 1. 战斗技能全解析

### 普通攻击：柔光兔兔弹
- **简述**：控制轮椅连续发射能量子弹，造成伤害。
- **详细机制**：
  > 斯帕克拉控制轮椅两侧的能量枪，向目标进行3次射击。

一段：攻击力[数值]地系普攻伤害

二段：攻击力[数值]地系普攻伤害

三段：攻击力[数值]x2地系普攻伤害

### 闪避动作：闪避动作
- **机制**：快速位移规避伤害，拥有极限闪避无敌帧，成功闪避可衔接疾跑或反击连携。

### 主控技能：兔子派重速切换
- **简述**：点按时进入「兔兔大开口模式」，慢速射击造成范围伤害。

长按时进入「兔兔速射模式」，快速射击造成多段伤害。

两种模式均可触发「地系印记」。
- **详细机制**：
  > 斯帕克拉控制轮椅，依据点按、长按，变形成不同的模式，持续10秒。

点按

进入###4033#，向目标抛射炸弹，造成攻击力[数值]地系技能伤害。

长按

进入「兔兔速射模式」，向目标高速射击，造成攻击力[数值]x3地系技能伤害。

「兔兔大开口模式」和「兔兔速射模式」均可触发「地系印记」，造成攻击力[数值]的范围地系印记伤害。

在变形结束后，进入冷却。

### 援护技能：兔兔追踪炮
- **简述**：斯帕克拉控制轮椅向目标位置发射多轮「兔兔礼花」，造成伤害。

「兔兔礼花」可触发「地系印记」。
- **详细机制**：
  > 斯帕克拉控制轮椅伸出机械臂向目标位置发射「兔兔礼花」，每轮发射2发，共发射13轮。

「兔兔礼花」在发射后会在目标附近随机落下，造成攻击力[数值]地系技能伤害。

「兔兔礼花」可触发「地系印记」，造成攻击力[数值]的范围地系印记伤害。

### 绝招：兔兔全域火力压制
- **简述**：斯帕克拉在轮椅上休息，命令玩偶自动打击自身附近的目标造成范围伤害。

醒来后再对目标位置造成范围伤害。

绝招可触发「地系印记」。
- **详细机制**：
  > 斯帕克拉在轮椅上休息，命令玩偶自动打击附近的目标，造成攻击力[数值]x10范围地系绝招伤害。

斯帕克拉醒来后再对目标发射「兔兔礼花炮」，造成攻击力[数值]范围地系绝招伤害。

绝招可触发「地系印记」，造成攻击力[数值]的范围地系印记伤害。
