# 小禾 官方流派与配队战斗指南

## 1. 核心定位与机制
- **定位**：地系核心旅人 (5 星)
- **战斗风格**：擅长利用地系印记与多样化战术机制进行持续压制与爆发输出。

## 2. 官方推荐战斗流派
- **官方推荐流派 1**：提升玩偶伤害并追加回复，提升持续作战能力的流派。
- **官方推荐流派 2**：提升换弹频率，更高频发动旋风射击的流派。
- **官方推荐流派 3**：提升抽奖结果中“企鹅”的概率，抛掷企鹅雕像，提升主控输出能力的流派。
- **官方推荐流派 4**：提升抽奖结果中“爱心”的概率，射出爱心箭矢，提升主控生存能力的流派。

## 3. 配队协同与印记联动
- **印记附着与引爆**：优先搭配具有快速挂载地系印记或具备高削韧能力的均衡/辅助旅人。
- **主控与援护战术分工**：
  - **主控登场**：利用「布偶乱步」控场与「慵懒连击」打出高频伤害，结合绝招「星梦大回旋」在敌方虚弱时爆发。
  - **援护后台**：前台队友破韧后瞬间触发「缤果奇缘」，登场瞬发压制。

## 4. 关键养成质变节点
- **突破 3 阶觉醒**：不仅解锁觉醒立绘，而且大幅度提升成长属性，是质变关键期。
- **潜能优先级**：潜能 1 与 潜能 2 是核心机制质变点，显著优化循环手感并带来机制层数加成。
