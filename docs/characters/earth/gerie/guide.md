# 格芮 官方流派与配队战斗指南

## 1. 核心定位与机制
- **定位**：地系核心旅人 (5 星)
- **战斗风格**：擅长利用地系印记与多样化战术机制进行持续压制与爆发输出。

## 2. 官方推荐战斗流派
- **官方推荐流派 1**：施放技能后，提升移速、攻击范围和伤害的普攻流派。
- **官方推荐流派 2**：提升技能链接目标数，并与角色产生连锁反应的技能流派。
- **官方推荐流派 3**：提升链铲数量，并可拖拽链铲额外造成伤害的爆发流派。
- **官方推荐流派 4**：角色持续存在并产生震荡的持续伤害流派。

## 3. 配队协同与印记联动
- **印记附着与引爆**：优先搭配具有快速挂载地系印记或具备高削韧能力的均衡/辅助旅人。
- **主控与援护战术分工**：
  - **主控登场**：利用「棘罪地狱」控场与「死亡尖吻」打出高频伤害，结合绝招「天恩·恶兆神罚」在敌方虚弱时爆发。
  - **援护后台**：前台队友破韧后瞬间触发「即刻处刑」，登场瞬发压制。

## 4. 关键养成质变节点
- **突破 3 阶觉醒**：不仅解锁觉醒立绘，而且大幅度提升成长属性，是质变关键期。
- **潜能优先级**：潜能 1 与 潜能 2 是核心机制质变点，显著优化循环手感并带来机制层数加成。
