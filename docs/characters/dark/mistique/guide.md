# 雾语 官方流派与配队战斗指南

## 1. 核心定位与机制
- **定位**：暗系核心旅人 (5 星)
- **战斗风格**：擅长利用暗系印记与多样化战术机制进行持续压制与爆发输出。

## 2. 官方推荐战斗流派
- **官方推荐流派 1**：提升技能范围与伤害、影灵消失后可爆破敌人的群伤流派。
- **官方推荐流派 2**：增强影灵的控制能力与持续作战能力，适合对付精英目标的流派。
- **官方推荐流派 3**：延长技能时长，持续增强场上影灵伤害的流派。
- **官方推荐流派 4**：使技能可牵引敌人并增强影灵的自爆攻击，适合近战主控的流派。

## 3. 配队协同与印记联动
- **印记附着与引爆**：优先搭配具有快速挂载暗系印记或具备高削韧能力的均衡/辅助旅人。
- **主控与援护战术分工**：
  - **主控登场**：利用「诡影重重」控场与「彗星连扫」打出高频伤害，结合绝招「午夜★不眠」在敌方虚弱时爆发。
  - **援护后台**：前台队友破韧后瞬间触发「怪奇门扉」，登场瞬发压制。

## 4. 关键养成质变节点
- **突破 3 阶觉醒**：不仅解锁觉醒立绘，而且大幅度提升成长属性，是质变关键期。
- **潜能优先级**：潜能 1 与 潜能 2 是核心机制质变点，显著优化循环手感并带来机制层数加成。
