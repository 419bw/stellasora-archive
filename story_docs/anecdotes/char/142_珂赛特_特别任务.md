# 珂赛特 · 特别任务

## 1. 逸闻笔记信息
- **所属人物**：珂赛特（编号 `142`）
- **收录笔记**：3 篇（`14201`、`14202`、`14203`）

## 2. 逸闻笔记全文


### 特别任务（一）

> - **笔记 ID**：`14201`　**获取条件**：携带珂赛特通关1次星塔

珂赛特来到诺瓦大陆之后，极光给她的第一个任务：调查星塔的结构，寻找能够炸毁星塔的办法。

听上去似乎不难。

在珂赛特的概念里，星塔就像大树，只要在底部找到合适的位置，放上足够的炸药，让一座星塔倒塌简直轻而易举。

于是她朝着城邦外最近的星塔走去，决定先去踩个点，只是……

珂赛特走了整整一个下午，明明星塔就在眼前，但她却像是在星塔底部绕圈一样，无论如何都无法靠近。

“到底为什么会这样……”


### 特别任务（二）

> - **笔记 ID**：`14202`　**获取条件**：携带珂赛特通关2次星塔

这可是极光大人交给她的第一个重要任务，无论如何，珂赛特都要好好完成。

于是她开始跟踪过往的旅人，在跟丢了三次、跟错了五次之后，终于，珂赛特尾随着一队旅人，找到了据说可以进入星塔的入口——一部升降梯。

于是，就在她眼睁睁地看着那群旅人上了升降梯，计划着等下一趟，自己也能进入星塔内部一探究竟时，升降梯在她面前消失了。

珂赛特跑到刚刚升降梯出现的位置，又在附近转了几圈，根本不敢相信自己的眼睛。

“诶？？怎么不见了？？难道说我刚刚跟踪的旅人……是幽灵？！”


### 特别任务（三）

> - **笔记 ID**：`14203`　**获取条件**：携带珂赛特通关3次星塔

经过多番调查取证，珂赛特终于找到了进入星塔的正确方法。

既然无法从外部靠近星塔底部，那么，只要在星塔内部放置好炸药，然后引爆，摧毁星塔的任务也能顺利完成！

因此，今天的任务就是，计算从放置了炸药的星塔底部，到彻底离开星塔所需要的时间……

正想着，珂赛特突然注意到旁边有一个商店，明亮的灯光打在一排排货架上，商品宛如沐浴在圣光之中，吸引着路过的行人。

珂赛特忍不住走过去……

“呜哇——！是饮料！！这是什么，完全没有见过的口味，这个也是，还有这个……！”

沉浸在喜悦中的珂赛特似乎把任务抛在了脑后。
