# 雾语 · 以身入局

## 2. 逸闻笔记全文


### 以身入局（一）

> - **笔记 ID**：`13501`　**获取条件**：携带雾语通关1次星塔

在撰写轰动弗拉维奥的“无良香料商”的报道时，为了混入被香料商雇佣的旅人队伍，雾语难得地把她最喜欢的扫帚和帽子都好好藏了起来，彻底伪装成了一个新手旅人。

“公司每天都要你们许愿些什么东西出来啊？”

“从喷雾器到储存罐——最关键的是，这些东西又重又大，居然要一个个搬出去……！”

“这么辛苦，待遇应该很好吧？”

“别提了，能正常发工资就不错了，他们有时还拿做好的香水来当工资发呢！”

这句关键的证言最后被精心安排在了副标题上，引发了众怒。

最后，香料商不得不出来驳斥，但却用了“这些香水实际上早就是硬通货了，完全可以起到等价物的作用”——之类的可笑说辞。


### 以身入局（二）

> - **笔记 ID**：`13502`　**获取条件**：携带雾语通关2次星塔

雾语还当过几天偶像。

为了揭露传闻中的黑箱操作，她化名打扮、参加了弗拉维奥的偶像选秀。凭借甜美的歌喉和夸张的演技，她征服了许多评委和粉丝，一路过关斩将来到总决赛的舞台。

成功潜伏的她，真的提前于决赛开始前，就瞥见了最终名次。

当发现自己因为没有自带赞助而被排在末尾时，她燃起了少有的斗志，并决定在舞台的现场把一切都揭发出来——

不出所料，雾语刚冲上台还没开口就被安保拖走丢出了场——但她也得以提前离开。

她紧急制作的报道，最终还是没能提前于选秀结果发出——组委会轻飘飘地用一句“这只是巧合的推测”，就将事情简单地压了下去。


### 以身入局（三）

> - **笔记 ID**：`13503`　**获取条件**：携带雾语通关3次星塔

魔女的工作向来伴随着风险——但像雾语这样被点名追杀的情况还是很少见的。

她那篇名为《传媒与能源——诺瓦的真相》的报道，仅仅只是稍稍揭开了一点点弗拉维奥和恩赐意志之间的公开秘密。

可从此以后，她的新闻就再也没法被接收登报了；绯曈传讯也公开表示《魔女保护条例》将不再适用于雾语。

对雾语来说，这次的以身入局最为彻底——她真的不再需要顾及什么版面、字数、截稿日了，只为自己兴趣去写报道就行。

也不再需要整日都待在城里等待绯曈的发号施令了——荒野和星塔里，往往也有精彩的新闻值得一写。
