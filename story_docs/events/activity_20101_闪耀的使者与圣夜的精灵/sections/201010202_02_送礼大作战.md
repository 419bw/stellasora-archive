# 02 送礼大作战

## 1. 关卡信息
- **所属活动**：闪耀的使者与圣夜的精灵（活动编号 20101）
- **关卡 ID**：`201010202`
- **AVG 剧本**：`STev_02_02`
- **关卡描述**：穿上制服，你与菈露来到了期待着礼物的孩子们身边……

## 2. 官方跳过概要

> 你与菈露开始给灰城区的孩子们分发起了雪愿节的礼物，还聊起了“用大炮发射礼物”的宏伟梦想……此时一个神秘的身影，引起了你们的注意。

**旁白**：「菈露带我来到仓库，里面堆满了打包好的礼物。」

**魔王**：「我们只有一个雪橇，装得下这么多礼物吗？」

**菈露**：「装不下也得装！不然今天肯定送不完了！」

**魔王**：「如果能把礼物当作炮弹，直接发射到孩子们手里就好了。」

**魔王**：「嗯？」

**菈露**：「要是能用魔法把大炮雪橇改装成礼物发射器，派送就方便多了。」

**菈露**：「以后的雪愿节，我只需要把名单上的地址设成落点，就能坐在办公室里轻轻松松送礼物了！」

**魔王**：「哦，要不要立刻试试？」

**菈露**：「我做不到啦。」

**魔王**：「那你这不是白日做梦嘛！」

**菈露**：「专业的事交给专业的人，我打算写个方案，发给星辉学馆的人。他们明年的研究项目这不就有了？」

**菈露**：「到时候真的研究出来了，我会让他们在致谢里写上你的名字~」

**菈露**：「“伟大的创意提出者——魔<r=mowang></r>王大人！”」

**菈露**：「魔<r=mowang></r>王应该不知道吧？在冬日的港口夜钓可是别有一番乐趣。」

**菈露**：「尤其是在冬天，雪愿节前后，还能看到会发光的鱼成群结队地浮上水面。简直像童话里的场景，特别漂亮！」

**魔王**：「还有会发光的鱼？」

**菈露**：「当然有了，有机会带你看看~」

**魔王**：「菈露很喜欢那种鱼啊……」

**菈露**：「它很漂亮，谁都会喜欢的。」

**魔王**：「我的意思是……你刚才提到它时，脸上的表情都变温柔了。」

**菈露**：「有、有吗？肯定是你看错了……总之，礼物已经装好了，我们赶紧走吧。」

**菈露**：「孩子们还在等着我们呢！」

**旁白**：「仿佛是为了掩饰什么，菈露拉着我匆忙离开了仓库。」

**魔王**：「说起来，雪愿节的礼物，是所有孩子都会收到吗？」

**菈露**：「没错。从今年起，大家都能收到哦。」

**魔王**：「今年起？」

**菈露**：「以前礼物只会发给金城区和银城区的孩子们。」

**菈露**：「但今年有人提议，只要是城邦里的孩子，都应该收到礼物。」

**菈露**：「所以，今年礼物发放的范围也涵盖了灰城区。」

**魔王**：「难怪连你这个摸鱼大王都在认真工作啊。」

**菈露**：「喂喂，我摸鱼也是有原则的！」

**菈露**：「“高质高效地完成工作后，尽情享受空闲时间”——是本人的摸鱼原则。也就是说，我会好好对待工作的。」

**菈露**：「而且这份工作可是很有成就感的，谁会想偷懒啊？」

**魔王**：「嗯？」

**菈露**：「你也知道，恩赐意志是“恩赐之神”的代理人嘛。」

**菈露**：「在一片欢声笑语中，他们闪闪发光的眼睛里充满了童真……那个画面，真是太可爱了。」
