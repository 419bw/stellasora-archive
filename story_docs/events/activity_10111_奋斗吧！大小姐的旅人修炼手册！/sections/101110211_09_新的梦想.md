# 09 新的梦想

## 2. 官方跳过概要

> 卡特琳与薇薇安向埃莉诺倾诉了真正的心愿，
> 三人决心组建一支“大小姐旅团”。
> 旅途中，她与你重逢。

## 3. 逐句台词

**埃莉诺**：「抱歉，让你们久等了！」

**卡特琳**：「埃莉诺你太慢啦，我们都等你好一会儿了！」

**埃莉诺**：「抱歉啦，卡特琳。准备出发前的装备和道具花了些时间，一不留神就迟到了……」

**薇薇安**：「下个委托地点是哪里？」

**埃莉诺**：「这次不是委托，我打算去挑战星塔。」

**薇薇安**：「哇，你终于要开始正式爬塔了吗？会不会很辛苦啊？」

**埃莉诺**：「想来不会太轻松。不过为了这一天，我已经做了非常充足的准备了，所以请放心。」

**薇薇安**：「真好呀，我其实一直很好奇星塔里面的样子呢。」

**埃莉诺**：「以后有机会的话，我会用绘画或者留影器记录下里面的景象，然后带回来给你们看。」

**薇薇安**：「但我听说星塔里的环境千变万化，如果没办法亲眼目睹，多少还是有些遗憾呢……」

**埃莉诺**：「薇薇安……」

**卡特琳**：「……咳咳。既然话都说到这里了…… 薇薇安，也该和埃莉诺讲清楚我们的想法了吧？」

**埃莉诺**：「诶？」

**薇薇安**：「是呢，现在就是最好的时机了。」

**薇薇安**：「埃莉诺，你还记得你完成第一个正式委托后的那次茶会吗？」

**埃莉诺**：「嗯……记得。」

**薇薇安**：「当时你问过我们一个问题对吧，问我们是不是会羡慕你现在的旅人生活——」

**薇薇安**：「我们可没有埃莉诺那么勇敢。如果非要说我们的愿望是什么……」

**薇薇安**：「我想，“想要找到属于自己的愿望”，或许才是我们真正的愿望吧。」

**薇薇安**：「现在，我们终于找到那个愿望了……」

**薇薇安**：「我们——想要成为旅人。」

**薇薇安**：「我们一直陪伴在你身边， 看着你成长，见到过你开心的笑容，也见过你碰壁时的沮丧。」

**薇薇安**：「你经历过的一切，都是我们所缺乏的、无比耀眼的东西…… 在不知不觉中，我们心里已经埋下了这样一个念头：我们想要像你一样，自由自在地活过一生。」

**卡特琳**：「除此之外，每次目送你踏上旅途的背影，我和薇薇安都会很寂寞…… 对于只能默默担心、却完全帮不上忙的自己，感到不争气。」

**薇薇安**：「所以埃莉诺，我们再也不想站在原地，目送着你离去了；我们要与你并肩走在同一条路上。」

**卡特琳**：「没错，而只要能当上旅人，我们就有机会实现这个愿望。」

**卡特琳**：「要是我们三个人能一起出发，踏上冒险的旅程……那该是一件多么美妙的事情啊。」

**埃莉诺**：「“一起……冒险”……」

**埃莉诺**：「要是真能够实现的话，确实很幸福……」

**埃莉诺**：「……这么说，你们难道想要与我一起出发去星塔吗？」

**薇薇安**：「总有一天会去的，但不是今天。现在的我们还不是旅人，要是硬拉着你带我们去，也只会是累赘。」

**卡特琳**：「这点自知之明我们还是有的，毕竟我们现在的差距实在是太大了。」

**卡特琳**：「所以，我们也打算像埃莉诺一样，先好好学习旅人的技能与知识，锻炼身体，直到不会给你拖后腿为止。」

**薇薇安**：「埃莉诺，请你再等上一段时间，我们一定会追赶上你的脚步。」

**埃莉诺**：「既然这样，就让我来帮忙吧！我有经验，肯定对你们的训练有帮助。」

**薇薇安**：「……真的可以吗？你现在的生活已经很忙碌了……」

**埃莉诺**：「当然！你们的愿望也是我的愿望，我也不想和你们分开。」

**薇薇安**：「埃莉诺，你人真好……或许正因为那是你追求的梦，我才会感到如此向往……」

**卡特琳**：「哇~你们俩可真肉麻……」

**埃莉诺**：「前辈！」

**埃莉诺**：「终于见到你了，前辈！」

**魔王**：「我刚到埃摩，没想到会在星塔附近遇到你。你已经开始独自一人爬塔了吗？」

**埃莉诺**：「是的！」

**魔王**：「嗯，还真是成长了很多啊……」

**魔王**：「说起来，之前你是不是解决了一桩案子，还营救了你的朋友？」

**魔王**：「虽然大致情况我已经了解，但还是希望能听你亲自讲述一遍。」

**埃莉诺**：「我也有很多话想对前辈说呢，您愿意听的话真是太好了！」

**魔王**：「原来发生过这么多事……」

**魔王**：「埃莉诺，你已经用行动证明了自己的能力。干得真漂亮。」

**埃莉诺**：「诶嘿嘿~感谢前辈的夸奖！」

**埃莉诺**：「其实，我今后打算陪我那两个好朋友，也就是薇薇安和卡特琳她们进行旅人特训。」

**魔王**：「她们或许是憧憬着你的背影，而立志走上这条路的，正如同过去的你。」

**埃莉诺**：「是的！所以我很想帮助她们…… 虽然这话听起来可能有些不自量力，但我想以前辈为榜样，哪怕只能尽到微薄之力，也要帮上她们的忙。」

**埃莉诺**：「等她们学会如何在荒野中保护自己后， 我们打算创立一个新的旅团，然后和大家一起去冒险！」

**魔王**：「旅团吗……呵呵，真是个了不起的目标啊。」

**魔王**：「一个人的力量是有极限的，想要攀登得更高，就需要他人的帮助。」

**埃莉诺**：「是啊，其实当我看到菲莱的旅人们在前辈的指引下齐心协力击败魔物时，我心中就一直有这样的想法了。」

**埃莉诺**：「我自己也是得到了前辈您、薇薇安和卡特琳，还有其他很多人的帮助才走到了今天，所以我很清楚人与人之间纽带的重要性。」

**魔王**：「做得很好。这么看来，我已经没什么可教给你的了……」

**埃莉诺**：「才不会呢！无论何时，前辈永远都是我的前辈。」

**埃莉诺**：「成为旅人，并且得到家人的认可…… 我过去的梦想已经实现了。」

**埃莉诺**：「但我不会就此停下脚步，因为现在的我，已经有了新的梦想和目标。」

**埃莉诺**：「我想创立自己的旅团，积累更多的经验，变得更加成熟，等到那个时候……」

**埃莉诺**：「我希望能与伙伴们一起加入魔王协议！」

**埃莉诺**：「前辈……可以吗？」

**魔王**：「呵呵，怎么会不行呢，这是我的荣幸。」

**埃莉诺**：「那就一言为定哦？」

**埃莉诺**：「今后，也请前辈继续见证我的成长吧！」
