# 07 尊者

## 1. 关卡信息
- **所属活动**：冬夜镇魂曲与破晓扳机（活动编号 10105）
- **关卡 ID**：`101050208`

> 你和风影与埃妲爆发了激烈的冲突，风影一时失手，意识被囚禁。而埃妲也宣告了她的真实目的：唤醒名为“尊者”的强大存在。
