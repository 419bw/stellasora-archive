## 🚀 快速阅读与本地使用

### 方式一：直接双击打开（离线阅读）
进入 `site/` 目录，直接用浏览器双击打开 [**`site/index.html`**](./site/index.html) 即可开始浏览与检索（搜索已做本地离线静态内嵌，无需网络支持）。

### 方式二：本地服务预览（推荐）
在项目根目录下运行 Python 内置服务器：
```bash
python -m http.server 8000 --directory site
```
然后在浏览器中访问：[http://localhost:8000](http://localhost:8000)
